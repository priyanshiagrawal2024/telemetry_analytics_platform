\# Project Context



Project:

MyJio Floater Analytics Platform



Objective:

Build an AI-powered telemetry analytics system for analyzing customer behaviour and floater engagement.



This is NOT a recommendation system.



Primary Goals:

\- Customer Analytics

\- Campaign Analytics

\- Fatigue Analytics

\- Segmentation Analytics

\- Trend Analytics

\- Insight Generation



Core Events:

\- impression

\- click

\- skip

\- conversion



Core Metrics:

\- Impression Count

\- Click Count

\- CTR

\- Skip Rate

\- Conversion Rate

\- Repeat Impression Rate

\- Time To Click

\- Time To Skip

\- Session Depth

\- Fatigue Score



Primary Grouping:

\- customerId

\- sessionId

\- campaign



Tech Stack:

\- Python

\- FastAPI

\- PostgreSQL

\- Pandas

\- Streamlit

\- Plotly

\- Google ADK



Important:

Never generate recommendation systems.

Never generate personalization systems.

Focus only on analytics and insight generation.
